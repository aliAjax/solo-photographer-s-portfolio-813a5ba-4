# 拍摄授权预算工作台

面向独立摄影师的纯前端工作台:建立客户与拍摄项目,按**拍摄天数、交付张数、授权区域、授权期限、传播渠道、折扣、税率**生成多版费用方案;方案实时校验冲突、展示可解释明细,支持复制、比较、撤销/重做、版本恢复与本地持久化。

## 运行

```bash
npm install
npm run dev       # 开发 http://localhost:5173
npm run build     # 类型检查 + 生产构建
npm run preview   # 预览生产构建 http://127.0.0.1:4173
npm run verify    # 真实浏览器端到端验证(自动拉起 preview,51 项断言)
```

## 功能与规则

### 数据模型
客户(Client)→ 拍摄项目(Project)→ 费用方案(Scheme)→ 已确认版本(Version)。方案的当前编辑内容称为**草稿(draft)**,只有显式「确认为版本」才固化为不可变快照(参数 + 明细 + 合计 + 时间戳)。

### 计价模型(可解释明细,`src/pricing.ts`)
| 行 | 公式 |
|---|---|
| 拍摄费 | ¥8,000 × 拍摄天数 |
| 精修交付费 | ¥300 × 交付张数 |
| 创作费小计 | 上两行之和 |
| 授权区域加价 | 小计 × 区域系数(单城 0 / 省级 30% / 全国 80% / 全球 150%) |
| 授权期限加价 | 小计 × 每月 2%(封顶 100%) |
| 传播渠道加价 | 小计 × 各渠道系数之和(官网 10% / 社媒 15% / 印刷 20% / 户外 25% / 电视 40% / 包装 30% / 独家买断 100%) |
| 折扣 | − 费用小计 × 折扣率 |
| 税费 | 折后金额 × 税率 |

每一行都展示「标签 + 计算公式 + 金额」,合计逐级可复核。

### 校验(`src/validate.ts`,实时)
- **字段错误**(阻断确认):天数/张数/期限需为 ≥1 整数且有上限;折扣 0–90%;税率 0–30%。
- **跨字段冲突**(阻断确认):至少选择一个渠道;「独家买断」与按渠道授权互斥。
- **警告**(不阻断):折扣 >30%、期限 >3 年、张数相对天数偏高。
- 存在任何错误或冲突时,确认按钮禁用、明细区显示无法计算;**非法输入永远不会写入已确认版本**——版本只在校验全部通过时由当前草稿快照生成。

### 编辑能力
- **撤销/重做**:按方案独立的草稿历史(同字段 1.2s 内连续输入自动合并为一步),按钮 + Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Z。
- **复制**:方案可复制为同参数新草稿;已确认版本可一键「恢复」为当前草稿。
- **比较**:任选两个已确认版本并排比较,参数与逐行明细的差异行高亮。
- **持久化**:客户/项目/方案/版本/草稿/选中态全部写入 `localStorage`,刷新或重开浏览器后原样恢复;读取时校验结构,丢弃损坏的版本数据。

### 响应式
- 桌面(>1100px):客户/项目 | 方案编辑 | 明细与版本 三栏。
- 平板:两栏。
- 手机(≤720px):单栏 + 底部导航(客户 / 方案 / 明细与版本),核心流程(建客户→建项目→编辑参数→看明细→确认/恢复版本)均可在移动端完成。

## 端到端验证 `e2e/verify.mjs`

Playwright + 真实 Chromium,对生产构建(`vite preview`)执行 10 组共 51 项行为断言,全部通过 UI 真实操作(非预设结果):

1. 建立客户/项目/方案并确认 v1(合计逐项与独立重算的公式交叉核对);
2. 连续修改参数,明细与合计实时联动,确认 v2;
3. 冲突(买断+单渠道)与非法输入(折扣 95%)阻断确认,版本数不变;
4. 撤销/重做逐步回退与前进;
5. 版本恢复后草稿参数与合计回到 v1;
6. 复制方案生成同参数副本;
7. v1/v2 并排比较,差异行高亮;
8. 刷新后客户/项目/方案/版本/草稿全部保持;
9. 非法输入后刷新,已确认版本不被污染;
10. 390px 移动视口下完成编辑与明细查看。
